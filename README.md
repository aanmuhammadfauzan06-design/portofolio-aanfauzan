# AAN MUHAMMAD FAUZAN — Portfolio V25

## Run in VS Code
1. Extract the ZIP completely.
2. Open the folder `aan-portfolio-v25` in VS Code.
3. Confirm `index.html`, `style.css`, `script.js`, and the `assets` folder are in the same root.
4. Open `index.html` with Live Server.
5. If an older page is cached, press Ctrl+Shift+R.

## Important
- `index.html` is the real VS Code version and uses local relative paths.
- `preview.html` is a standalone preview with CSS, JavaScript, and images embedded, so it does not depend on sibling files.
- All supplied portfolio images are included in `assets/`.
